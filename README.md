# ProdLab

Static lab for production backend system design. ES / EN. No backend, no tracking.

## Deploy on Vercel

1. Import `Rompni/prodlab`.
2. Framework preset: **Other**. Root directory: repo root.
3. After you have the URL, replace `https://prodlab.vercel.app` in:
   - `index.html` (canonical, og, hreflang, JSON-LD)
   - `sitemap.xml`

Optional: add `og.png` at the folder root (1200×630). Meta tags already point to `/og.png`.

## Local

```
npx serve .
```
